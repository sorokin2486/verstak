# Формат файлов Верстака

Деталь — это подпапка библиотеки (по умолчанию `D:\Verstak\<id>\`):

```
D:\Verstak\easel-bracket\
  drawing.json        пишет только Claude
  measurements.json   пишет только приложение (Claude только читает)
  photo.jpg           необязательно
  .history\drawing.rN.json   копии ревизий чертежа
```

Приложение следит за библиотекой: новая папка или новая ревизия `drawing.json` появляется без перезапуска.

## drawing.json — `verstak/1`

```jsonc
{
  "format": "verstak/1",
  "id": "easel-bracket",            // = имя папки
  "title": "Кронштейн полочки",
  "revision": 1,                    // +1 при каждой правке чертежа
  "units": "мм",
  "scale": "без масштаба",          // необяз.
  "intro": "…",                     // необяз., абзац под заголовком
  "steps": ["…", "…"],              // необяз., как мерить
  "stamp": { "Кол-во": "2 шт." },   // необяз., доп. строки штампа
  "legend": { "part": "деталь", "hidden": "углубление", "section": "стенка ребром" },
  "commentHint": "…",               // необяз., подсказка в поле комментария
  "changes": "…",                   // необяз., что поменялось в этой ревизии (видно в баннере)
  "groups": [ { "id": "fit", "title": "Посадка", "note": "…", "critical": true } ],
  "params": [
    { "id": "A", "label": "Длина полки", "group": "fit",
      "kind": "length",       // length | diameter | radius | angle | count
      "critical": true,       // рамка оранжевая, мерить до 0.1
      "approx": 55,           // оценка по фото → предупреждение, если ввели в 2+ раза больше/меньше
      "hint": "по дну паза",
      "optional": true }
  ],
  "views": [ {
    "id": "side", "title": "Вид сбоку",
    "box": [minX, minY, width, height],   // viewBox; Y вниз
    "shapes": [ … ],
    "dims": [ … ]
  } ]
}
```

### Фигуры (`shapes`)

| type | поля |
|---|---|
| `path` | `d` — только команды `M L H V A C Q S T Z` и числа |
| `rect` | `x y w h`, `rx` |
| `circle` | `cx cy r` |
| `line` | `from: [x,y]`, `to: [x,y]` |
| `polyline` | `points: [[x,y],…]`, `closed` |
| `text` | `at: [x,y]`, `text`, `size`, `anchor` |

`style`: `part` (деталь, заливка, по умолчанию) · `hidden` (углубление/невидимое, пунктир) · `section` (штриховка) · `center` (осевая) · `thin` (тонкая линия).

### Размеры (`dims`)

Размер только ссылается на параметр (`param`), подпись и стрелки рисует приложение. Один параметр можно показать на нескольких видах.

| type | поля | смысл |
|---|---|---|
| `hdim` | `x: [x1, x2]`, `y`, `ext: [y1\|null, y2\|null]` | горизонтальный размер на высоте `y`; `ext` — y точек детали, от которых идут выносные линии |
| `vdim` | `y: [y1, y2]`, `x`, `ext: [x1\|null, x2\|null]` | вертикальный размер на абсциссе `x` |
| `leader` | `at: [x,y]`, `label: [x,y]` | выноска: точка на детали → подпись |

Размер короче 80 единиц (при высоте вида 1330) рисуется со стрелками снаружи и подписью над линией.

### Масштаб и компоновка

- Виды стоят в ряд с одинаковой высотой, ширина по пропорции `box`. Дай всем видам **одинаковую высоту `box`**, тогда они в одном масштабе.
- Толщина линий и размер подписей пропорциональны высоте `box` (база — 1330). Удобно рисовать в «пикселях» листа с высотой вида ≈ 1000–1400.
- Оставляй под размеры поля вокруг детали: ~150 единиц снизу и сверху.

## measurements.json — `verstak-measurements/1`

```jsonc
{
  "format": "verstak-measurements/1",
  "drawingRevision": 2,          // последняя ревизия, которую пользователь подтвердил
  "status": "in_progress",       // "done" — пользователь нажал «Готово, передать Claude»
  "comment": "сопло 0.4, PETG",
  "values": {
    "A": { "value": "55.2", "updated": "2026-11-22T10:44:41Z", "drawingRevision": 2 }
  },
  "log": [ { "at": "…", "param": "A", "from": "55", "to": "55.2" } ]
}
```

- `value` — строка как ввёл пользователь (запятая → точка). Может быть `"40/38"` для сужения.
- Значения параметров, которых нет в новой ревизии, не удаляются.
- Запись атомарная (временный файл + переименование): читать можно в любой момент.
